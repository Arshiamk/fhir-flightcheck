# Contributing

FHIR Flightcheck is currently in its v1 single-author phase. External code
contributions and pull requests are not merged during this phase — this policy
ensures a consistent commit history and is enforced by the repository's
authorship check.

**What is welcome:**

- Bug reports and security disclosures via [GitHub Issues](https://github.com/Arshiamk/fhir-flightcheck/issues)
- Design and architecture feedback
- Documentation corrections (typos, broken links, unclear wording)
- Feature requests and rule suggestions

**Security vulnerabilities:** Please do not file public issues for security
vulnerabilities. Open a [GitHub Security Advisory](https://github.com/Arshiamk/fhir-flightcheck/security/advisories/new)
instead.

This policy will be reconsidered after the first stable release.
