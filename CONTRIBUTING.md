# Contributing

FHIR Flightcheck version 1 is maintained as a single-author project. Issues,
reproducible bug reports, rule proposals, and design feedback are welcome.
External code commits are not merged while this authorship policy is active.

When reporting a problem:

1. use synthetic data only;
2. include the Flightcheck and rule-pack versions;
3. attach redacted machine-readable output where possible; and
4. describe the expected and observed behavior.

The project follows the Contributor Covenant for community interactions.
